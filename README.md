## 🌟 核心特色 (Core Features)

1. **📖 完整收錄 131 把武器全檔案**
   - 包含主武器（步槍、戰鬥步槍、狙擊槍&反器材步槍、衝鋒槍、霰彈槍、機槍/重型武器）、副武器（手槍、左輪手槍、衝鋒手槍、其他）及特殊武器（特別、事件、開發團隊限定）。
   - 每一把武器具備完整的 6 大核心板塊：個人資料、彈藥矩陣、DATA SHEET 數據總覽、可用配件槽位、戰地情報冷知識、專家戰術建議。

2. **⚖️ 全系列自由雙武器對比系統 (Free Head-to-Head Comparison)**
   - **Excel 級頂部凍結窗格 (Freeze Pane)**：滾動時雙武器對決橫幅永遠鎖定在頂端。
   - **超寬劇院級視窗 (Ultra-Wide GUI)**：支援最大 1720px 寬度，左右並列雙彈藥矩陣表格舒適不擁擠。
   - **即時更換全系列武器**：置頂窗格直接內建全系列武器下拉選單，支援跨系列秒換對比。
   - **彈藥矩陣火力深度對照**：對比標準子彈致死率與所有支援彈藥類型。
   - **AI 戰術裁決**：CQB 近戰勝出者、中遠距離勝出者、可靠度與續航力勝出者。

3. **🚀 100% 靜態部署 (Zero Configuration)**
   - 原生 HTML5 + CSS3 + Vanilla JavaScript，無需任何後端或伺服器建置。
   - 完美相容 Vercel、GitHub Pages、Cloudflare Pages 等靜態託管平台。

## 🚀 部署至 Vercel 指南 (Deploy to Vercel)

1. 將本倉庫推送到 GitHub 私人倉庫（Private Repository）。
2. 前往 [Vercel](https://vercel.com) 並使用 GitHub 帳號登入。
3. 點選 **"Add New..."** → **"Project"**。
4. 在專案列表中選擇剛剛建立的 GitHub 私人倉庫，點選 **"Import"**。
5. Framework Preset 保持預設（**Other**），無需填寫任何 Build Command 或 Output Directory。
6. 點選 **"Deploy"**，約 10 秒內即可在線上發佈專屬網址！
